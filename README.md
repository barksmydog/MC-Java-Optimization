# MC-Java-Optimization
This contains the steps to optimize your MC java experience.
Firstly, you need to download the Prism Launcher.exe and the Fabulously Optimized mrpack file.
Run the Prism Launcher.exe to setup Prism Launcher. Sign in with your Microsoft account and if you want, import all your servers and worlds and stuff.
Then click "Add Instance" and click "Import". Then hit browse and find your Fabulously Optimized file.
Put in all your other mods, shaders, and resource packs if you want and hit launch.
